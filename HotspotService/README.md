# Wi-Fi 热点守护

HotspotService（移动热点守护助手）是一个面向 ClassIsland 的 Windows 移动热点守护插件。它会持续关注系统热点状态，并按照预设的守护目标自动执行同步，减少重复手动开启或关闭热点的操作。

## 适用场景

在教室、一体机或其他公共终端场景中，词典笔、平板和其他需要临时联网的设备常常依赖 Windows 的“移动热点”功能。HotspotService 的目标，是把热点的开关控制纳入一个更稳定、可自动化、可规则化的守护流程里。

## 基本概念

- 守护开启/关闭：守护开启后，后台服务每 10 秒检查一次系统热点状态；守护关闭时，只记录状态，不主动干预系统热点。
- 守护目标：插件期望系统热点保持的目标状态，可选为“开启”或“关闭”。

## 当前功能

- 提供独立设置页，可设置：
  - ClassIsland 启动时是否自动开启守护
  - 启动时默认守护目标是开启热点还是关闭热点
- 支持手动开启或关闭守护服务
- 支持手动修改守护目标，并立即应用到当前系统热点状态
- 显示守护状态、守护目标、系统热点状态、最近检查时间和最近错误
- 提供 3 个自动化动作：
  - 开启热点守护
  - 关闭热点守护
  - 修改守护目标（开启热点 / 关闭热点）
- 提供 3 个规则集判断条件：
  - 守护状态
  - 守护目标
  - 系统热点状态
- 当系统热点状态与守护目标不一致时，自动执行同步并在后续轮询中重试

## 守护逻辑

- 守护状态和系统热点状态是两套状态
- 只有守护开启时，插件才会主动干预系统热点
- 关闭守护不会强制关闭系统热点
- 修改守护目标时，如果选择立即应用，会马上同步当前热点状态
- 守护过程中如果出现异常，会记录最近错误，并在后续轮询时继续尝试恢复
